PROJECT DESCRIPTION:
This portfolio represents an executive-level web application engineered with 
MERN Stack technologies (MongoDB, Express.js, React 19, Node.js), ultra-responsive 
glassmorphic UI, and production-grade DevOps automation.

--------------------------------------------------------------------------------
3. TECH STACK & ARCHITECTURE
--------------------------------------------------------------------------------
- Frontend:  React 19, Vite, Tailwind CSS v4, Framer Motion, Lucide React, EmailJS
- Backend:   Node.js v20, Express.js, MongoDB (Mongoose ORM)
- Security:  Helmet, Rate Limiter, Express Validator, CORS
- DevOps:    Docker (Multi-stage + Nginx), Docker Compose, GitHub Actions CI/CD

--------------------------------------------------------------------------------
4. CORE SECTIONS & FEATURES
--------------------------------------------------------------------------------
1. Hero Section: Executive profile, role carousel, glassmorphic stats.
2. Tech Arsenal: Categorized tabs (All, Frontend, Backend & APIs, Database & Cloud, Tools & Security).
3. About & Specialties: Full-stack architecture & API integration breakdown.
4. Services: Interactive service cards & scope modal.
5. Contact System: Dual EmailJS + MongoDB submission.
6. Footer: Custom SVG wave separator, quick navigation links.
